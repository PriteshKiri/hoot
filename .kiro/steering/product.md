# Product: Hoot

Hoot is an open-source, real-time quiz and polling platform inspired by Kahoot and Mentimeter.

## Target Users

- **Admins** (hosts): teachers, team leads, event organisers who create and run quiz sessions
- **Participants**: attendees who join via a short code or QR code on any device — no app install required

## Core Features

1. **Event authoring** — create quiz decks with multiple question types (single-select, multi-select, open text, rating scale, image-based)
2. **Publishing** — generate a 6-char join code and QR code; share a URL
3. **Live sessions** — real-time synchronisation via Supabase Realtime (Broadcast + Presence)
4. **Scoring** — speed-weighted scoring (max 1000 pts/question), server-authoritative
5. **Leaderboard** — live rankings after each question and a final podium
6. **Analytics** — per-question response distribution, average response time, CSV export
7. **Theming** — 5+ built-in colour themes, custom primary/background/font, logo upload
8. **Mobile-first** — works on any browser, 320 px–2560 px viewports, 44 px touch targets
